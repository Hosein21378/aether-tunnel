# Aether Tunnel

سیستم تانل چندسروره مبتنی بر **Xray** با مسیریابی هوشمند

## ویژگی‌ها

- نصب با **یک خط دستور**
- پشتیبانی از تعداد نامحدود نود (Entry / Relay / Exit)
- مسیریابی هوشمند بر اساس Latency و وضعیت سرور
- پنل مدیریت تحت وب
- هسته Xray (پشتیبانی از VLESS + Reality، Trojan و ...)
- خروجی خودکار لینک ورود به پنل + رمز عبور بعد از نصب

---

## روش نصب

### روش ۱: نصب یک‌خطی (بعد از آپلود روی گیت‌هاب)

بعد از اینکه پروژه رو روی گیت‌هاب خودت آپلود کردی، این دستور رو روی سرور اجرا کن:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/USERNAME/aether-tunnel/main/install.sh)
```

> `USERNAME` را با نام کاربری گیت‌هاب خودت جایگزین کن.

### روش ۲: نصب دستی (الان)

اگر هنوز روی گیت‌هاب آپلود نکردی:

```bash
# ۱. فایل‌ها را روی سرور آپلود کن
# ۲. سپس این دستورات را بزن:

cd /path/to/aether-tunnel
chmod +x install.sh
sudo bash install.sh
```

---

## بعد از نصب چه اتفاقی می‌افتد؟

اسکریپت به صورت خودکار:

1. هسته **Xray** را نصب می‌کند
2. پوشه‌های مورد نیاز را می‌سازد
3. یک **رمز عبور تصادفی** تولید می‌کند
4. سرویس را راه‌اندازی می‌کند
5. در انتها این اطلاعات را به تو نشان می‌دهد:

```
لینک ورود به پنل:  http://IP-SERVER:2053
نام کاربری:       admin
رمز عبور:         xxxxxxxxxxxxxx
```

## ساختار پروژه

```
aether-tunnel/
├── install.sh              ← اسکریپت نصب یک‌خطی
├── cmd/panel/              ← برنامه اصلی پنل
├── internal/
│   ├── config/             ← تنظیمات
│   ├── models/             ← مدل‌های داده (Node, User, Route)
│   ├── routing/            ← منطق مسیریابی هوشمند
│   ├── xray/               ← مدیریت هسته Xray
│   ├── api/                ← API های پنل
│   └── auth/               ← احراز هویت
├── web/                    ← فرانت‌اند پنل
└── configs/                ← فایل‌های پیکربندی نمونه
```
